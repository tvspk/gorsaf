# Gorsaf Abercastell

A game for learning Welsh (intermediate level, South Wales): cases on a space station, flashcards, Mnemo Hooks with
memory hooks, a mock exam and recorded Welsh audio. This repository holds the **English app "Gorsaf Abercastell EN"**
(Android) and its web version.

- **Web:** https://tvspk.github.io/gorsaf/ (works offline once opened).
- **Android:** https://github.com/tvspk/gorsaf/releases/latest/download/gorsaf-en.apk. Install it over the previous
  version and your progress stays.
- **Sync between devices** (phone, tablet, computer): *Sync* at the bottom of the desk. Progress travels encrypted
  (AES-256-GCM, key from an 8-word pairing code that never leaves your devices) through **your own private** GitHub
  repository. There is no server. The token and the code are stored only on each device.

Welsh voices: Piper CY-EN, Bangor University (Uned Technolegau Iaith), CC BY 4.0. The Welsh text and pronunciation have
not been checked by a native speaker.

For development, see `CLAUDE.md` and `HANDOFF.md`.
